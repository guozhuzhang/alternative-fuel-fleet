# 替代燃料船舶数据中心

静态交互页面，展示截至2026年8月31日的全球替代燃料船舶投用量、订单量、Fuel Ready及电池动力分类。

## 数据版本

数据来源：Clarksons Research WFR数据库；上海国际航运研究中心整理。

- 替代燃料投用船舶：3,178艘、18,613.71万GT
- 替代燃料船舶订单：2,181艘、17,276.74万GT
- Fuel Ready现有船队：1,566艘、11,511.00万GT
- Fuel Ready订单：1,350艘、8,551.15万GT
- 电池动力投用船舶：953艘，其中纯电141艘、混合动力812艘
- 电池动力订单：567艘，其中纯电50艘、混合动力517艘

## 统计口径

- 投用量采用In Service口径；订单采用On Order、Order或Contract等订单状态口径。
- 替代燃料船舶与Fuel Ready船舶分别统计，不跨类型去重，也不直接相加。
- 燃料合计等于单一燃料加组合参与。一艘组合船可以进入多个相关燃料类别。
- 多种替代燃料组合按船舶去重，每艘组合船只计一次。
- 电池动力中纯电动单列，除纯电外的其他电池动力归入混合动力。
- 页面显示的船型总计为去重总计。燃料列包含组合燃料的多标签统计，且不包含单列的电池动力，因此燃料列之和不等于去重总计。

## 数据边界

替代燃料明细在生成网页前完成分类和总量校验。公开页面不上传原始WFR文件，也不提供船名和Hull No。Fuel Ready当前使用8月31日总量数据，不以7月逐船明细替代8月分类明细。
